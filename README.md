# Network Security: Theoretical & Practical Defense
**Asim Shakeel | NUCES-FAST**

This repository serves as a comprehensive portfolio of my work in the Network Security course (CSC4065). It spans formal protocol verification, cryptographic implementation, and practical threat detection.

## 🚀 Key Technical Highlights

### 🛡️ Defensive Engineering (Suricata & iptables)
* Engineered **Suricata IDS rules** to detect RCE attempts and unauthorized SSH root logins.
* Implemented **iptables policies** for granular traffic control, including ICMP and HTTP filtering.

### 🔑 Cryptography & PKI
* Managed **X.509 certificate lifecycles** using OpenSSL.
* Performed **TLS traffic decryption** in Wireshark using `SSLKEYLOGFILE` to inspect encrypted application data.

### 🔍 Protocol Analysis & Vulnerability Research
* Modeled and verified SSO protocols using **AnB (Alice & Bob)** notation and the **OFMC Model Checker**.
* Conducted a case study on **GitHub's Supply Chain Security**, including an attack tree for OAuth token theft and malicious PR injections.

## 📂 Modules
1. **Protocol Analysis:** Formal verification of authentication logic.
2. **PKI & Traffic:** Practical encryption and packet inspection.
3. **Threat Detection:** Active defense via Firewalling and IDS.
4. **Exploits & Risk:** High-level vulnerability assessment of global platforms.
